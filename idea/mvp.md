# MVP - контент-завод, самая маленькая версия, которая уже работает

**Дата:** 2026-09-10
**Статус:** черновик, ждёт цифр автора (раздел «Вопросы к автору»)
**Опирается на:** `idea/superidea.md`, `idea/proof-of-value.md`, `idea/references.md`, `idea/deep-research.md`, `idea/precedents.md`, `idea/risks.md`, `idea/principles.md`, `.business/` (team, costs, unit-economics, content, funnel, kpi, monthly, products)
**Тип проекта:** (в) автономная агентная система под мой процесс внутри Ovre.

## Какой это случай

**(в) Автономный агент под процесс.** Не продукт на внешних людей (MCP наружу
отложен ещё в `why-now.md`), не фича поверх чужого инструмента. Значит,
минимум - это **один поток, который агент доводит до конца по одному поводу
запуска, без меня в цикле**. Единственная точка, где остаётся человек, - кнопка
«выложить», и она стоит там по моему же правилу 90% из `superidea.md`, а не
потому что поток не доведён.

Дальше говорю в этих терминах: повод запуска, поток, результат, гейт.

## Моё несправедливое десятикратное преимущество

> **Моё несправедливое десятикратное преимущество - это ежедневная, без
> единого пропуска, история моих собственных вещей и моих собственных постов:
> что продалось, что стоит, какой размер кончился, какой пост тянет
> сохранения и пересылки. Агент собирает её за две минуты и за копейки
> каждое утро, а человек не собирает вообще, потому что это десять часов
> скучной работы в месяц. Через тридцать дней у Ovre есть то, чего нет ни у
> Tati, ни у The Inka, ни у любого, кто скачает те же скиллы: основание для
> строки «почему эта вещь и почему сегодня» и базовая линия для петли
> «выложили → посмотрели продажи».**

Это не отрыв в одной сторис. Это отрыв в том, что стоит под сторис.
Подробный разбор, где отрыв есть, а где его нет, - в разделе «Ось отрыва».

## Минимальная версия одной фразой

> **Каждое утро в назначенное время (повод) агент сам снимает состояние вещей
> Ovre и наших постов, сравнивает со вчерашним и присылает в Telegram одну
> готовую сторис: наше обработанное фото одной вещи, текст в тоне бренда и
> строку «почему эта вещь сегодня», взятую из живых данных, а не из головы
> (результат). Закрывает боль «что выложить сегодня» в те 2–3 дня в неделю,
> когда своей идеи нет, и одновременно ловит, где кончился ходовой размер по
> топовой модели (одна боль).**

Это сцена из `proof-of-value.md` с одним изменением: четвёртый повод «о вещи
больше всего спрашивают» заменён на «пост с этой вещью собрал больше всего
сохранений и пересылок за неделю». Причина: Direct - это переписка с
клиентками, ПДн, и по `CLAUDE.md` в модель не идёт; своя статистика поста в
Instagram - те же данные об интересе, но без единого имени.

### Что в потоке (и без чего пользы нет)

| Шаг | Что делает | Без этого польза наступит? |
|---|---|---|
| 1. Повод | Cron, одно время утром, без нас | Нет. Без повода это «кнопка», а не поток |
| 2. Снимок вещей | Берёт цену и остаток по размерам каждой из 18 позиций из нашего же источника (см. «Открыто»), пишет в журнал за дату | Нет. Без него строка «почему сегодня» врёт, а это первый факап по `risks.md` §5 |
| 3. Снимок постов | Берёт по своим публикациям @ovre.brand охват, сохранения, пересылки, переходы в профиль через официальный Graph API (свой аккаунт, разрешено) | Нет. Это замена закрытому Direct как источнику «что интересно» |
| 4. Разница со вчера | Код, не модель: что продалось, что стоит N дней, где ноль в XS–M, какой пост в топе за 7 дней | Нет. Это и есть «повод» для вещи; и это единственное, что копится |
| 5. Выбор вещи и повода | Модель выбирает одну вещь по правилам из `proof-of-value.md` (лучше всех / последняя / без движения / больше всего сохраняют), берёт её обработанное фото из реестра | Нет. Это результат |
| 6. Текст | Модель пишет 1–2 строки в тоне `values.md` + `brand-guidelines.md`, без цен в тексте (цена живёт в Tilda) | Нет. Это результат |
| 7. Отправка | Telegram: фото + текст + строка «почему» + три строки сводки (продалось / стоит / кончился размер). Кнопки «да» / «нет + одна фраза» | Нет. Без Telegram мы это не увидим |
| 8. Журнал решений | Каждое «да / нет» и фраза - в файл. Считается % принятого без правок с первого дня | Нет. Это бенчмарк из `superidea.md`, без него контроль не передать |

Восемь шагов, из них модель нужна в двух (5 и 6). Всё остальное - скрипты.
Совпадает с правилом «ум дорогой, конвейер дешёвый» из `why-now.md`.

### Чего в потоке нет намеренно

- Публикации в Instagram. Гейт «да» остаётся на человеке до 90%.
- Видео. Сторис - картинка из нашего фото. Reels - потом.
- Чужих брендов. Ни одного скрейпера, пока свои данные не идут ежедневно
  (правило 4 из `principles.md`).

`references.md` один вопрос: без этого первая польза наступит? Если да -
пункт здесь.

|---|---|---|
| MCP-коннектор, «другие могут взять и настроить» | Да. Это про чужую жизнь, не про нашу (`proof-of-value.md`) | После того как сцена отработала месяц у нас |

Конкуренты отвечают на «как показать», а не на «что» (`proof-of-value.md`); правило 4 запрещает до своих данных | Когда журнал вещей и постов идёт 30 дней подряд без дыр |
| Подсмотр «как похожую вещь подавали бренды, за которыми следим» (шаг 4 сцены) | Да. Это тот же скрейпер, только маленький. Первый месяц подачу задаёт `content.md` и наши же лучшие посты по сохранениям | Вместе с досье |

Плюс метка AI-профиля с 31.08.2026 и 72% Gen Z, наказавших бренд (`deep-research.md`) | Только после того как ткань в кадре проходит четыре чек-пункта Fit / Fabric / Print / Logo |
| Автомонтаж (autocut), HTML-шаблоны сцен, HyperFrames, video-use | Да. Видео нет в минимуме | Когда сторис из фото держит 90% |
| Автопостинг через Graph API, первый комментарий, разброс по времени | Да. Гейт снимается по бенчмарку, а не заранее | Когда «да» без правок держится на 90% месяц |
| Много аккаунтов, «полосы», вариативность в JSON сцен | Да. Один аккаунт, один бренд | Не раньше, чем один аккаунт даёт измеримые продажи с контента |
| Пять форматов из одного источника (рилсы, длинное, карусель, короткий пост, блог) | Да. Один формат: сторис | После Reels |
| Три бизнеса (БАДы, памятники) | Да. Одно дело: Ovre (`superidea.md`, уточнение 1) | После того как Ovre-поток отработал квартал |
| Trial Reels как A/B-стенд хука, 3–5 вариантов первых секунд | Да. Это про Reels | Вместе с видео. Это первый кандидат на вторую ось отрыва, см. ниже |
| 20–40 вариантов среды вокруг одного живого лука, отбор по предсказанному CTR (Marketing Science) | Да. Отбор по метрике невозможен без журнала, который минимум только начинает копить | Когда в журнале есть 2–3 месяца связи «пост → сохранения → заказы». Второй кандидат на ось отрыва |
| Comment-to-DM, аватар в Direct через ChatPlace (модель Lu do Magalu) | Да. Это про закрытие сделки, а не про «что выложить». Отдельная и, возможно, более денежная идея | Отдельный файл в `idea/`, отдельный чат |
| Кнопка у продавца «откуда пришла / что спросила» (таблица в `principles.md`) | Да, польза сторис наступит и без неё. Но без неё нет базовой линии Direct → заказ | Не в потоке агента. Это разговор с продавцом, см. «До первой строчки кода» |
| Strategy-файл, который агент правит по метрикам; LLM-судья сценария с порогом; список запрещённых слов | Да. Первый месяц судья - Марина, её «нет» с фразой и есть правка стратегии | Когда накопится 30+ решений |
| Досье про нас с транскрипциями своих Reels | Да. Нужны только цифры постов, не транскрипты | Вместе с досье конкурентов |
| Реестр фото с дырами и списком «что доснять» | Частично. Для первого запуска нужна только папка «вещь → готовое фото». Список дыр - позже | Вторая неделя |
| Постинг в TikTok / YouTube, фермы, прогрев | Да и не подходит (`references.md` §7) | Никогда для бренд-аккаунта |

Итог: из суперидеи в минимуме остались повод по времени, знание о состоянии
своих вещей, свои фото, Telegram и журнал «да / нет». Ровно то, что
`proof-of-value.md` назвал нужным, минус подсмотр за брендами.

## Расчёт: качество против себестоимости

Одна реальная задача из минимума: **утро, надо решить, что выложить сегодня в
сторис, и сделать её; заодно узнать, что вчера продалось и где кончился
размер.** Две задачи в одной, потому что в потоке они неразделимы: без второй
первая пустая.

### Как это делают сегодня, без системы

Есть два живых пути.

**Путь А. Марина с телефона, своим глазом.** Сторис выходят каждый день,
своей идеи нет 2–3 раза в неделю (`proof-of-value.md`). Остатки и цифры
постов при этом не проверяются: по `kpi.md` конверсия Direct и связь «пост →
заказ» не меряются вообще, по `funnel.md` тоже. То есть вторая половина
задачи сегодня **не делается никем**.

**Путь Б. Я через Claude, руками.** 2026-09-08: картинка под распродажу,
около 20 минут, фото взято у чужого бренда (`proof-of-value.md`).

**Путь В (из `references.md` §11, для полноты).** Подрядчик на ведение
аккаунта: $90 за аккаунт в месяц по западным ставкам. Не знает остатков, не
видит наших цифр, делает по ТЗ раз в неделю. Белорусская ставка SMM мне
неизвестна - см. вопросы.

### Как это делает решение

Цены токенов - из актуальной справки по API на 2026-09-10 (Opus 5: $5 вход /
$25 выход за 1M; Sonnet 5: $2 / $10; Haiku 4.5: $1 / $5). Курс из
`unit-economics.md`: 1 USD ≈ 3,28 BYN.

Оценка одного утреннего прогона (моя оценка объёма, проверить на первом
запуске по `usage` в ответе API):

| Что уходит в модель | Токенов |
|---|---|
| Таблица вещей на сегодня (18 позиций × размеры, компактно) | ~3 000 |
| Вчерашний журнал и разница | ~3 000 |
| Свои посты за 30 дней с метриками, компактно | ~4 000 |
| `values.md` + `avatar.md` + `brand-guidelines.md` (стабильно, кэшируется) | ~6 000 |
| Реестр фото, инструкция | ~3 000 |
| **Вход всего** | **~20 000** |
| Выход: выбор, текст сторис, строка «почему», сводка (с рассуждением) | ~3 000 |

| Модель на шаги 5–6 | За прогон | За 30 прогонов | В BYN/мес |
|---|---|---|---|
| Opus 5 | ≈ $0,10 + $0,075 ≈ **$0,18** | ≈ $5,3 | ≈ **17 BYN** |
| Sonnet 5 | ≈ $0,04 + $0,03 ≈ **$0,07** | ≈ $2,1 | ≈ **7 BYN** |

С кэшированием стабильной части (`.business/`-файлы) вход дешевеет ещё
примерно на четверть. Шаги 2–4 и 7–8 - скрипты, токенов не тратят.
Graph API и Telegram-бот бесплатны. Прогон целиком: 2–4 минуты стены,
человеческих минут - ноль до момента, когда мы открываем Telegram.

Постоянные: место, где это крутится. Либо мой компьютер по расписанию (уже
проверено, что «работает по расписанию без меня» - `why-now.md`), либо VPS.
Цену VPS вписать, если выберем его.

Разовые: сборка потока. По рейт-карте из `deep-research.md` «content pipeline
(AI-heavy)» на рынке стоит $5 800–11 000 флэтом. У меня это вечер-два
собственной работы, оценка моих часов - в вопросах.

## Ось отрыва: где десятикратно, а где нет

### Где отрыва нет, честно

**Сторис как таковая.** 20 минут у меня, у Марины, вероятно, меньше и лучше
по вкусу. Машина делает за 2 минуты. Это не десять раз, это удобство. И
`risks.md` §2 прямо говорит: контент у Ovre не узкое место, охват уже 284 тыс.
за 30 дней, люди отваливаются на размере, доверии и в Direct. Если бы минимум
был только «черновик сторис в Telegram», отрыва бы не было, и я бы это
записал.

**Разведка конкурентов.** Здесь отрыв как раз есть, и большой: ручная
таблица «одна строка = один пост» даёт паттерны через 2–4 недели по одному
конкуренту (`references.md` §11), агент разбирает трёх конкурентов по 30
роликов за вечер. Недели → вечер, это классический десятикратный ход из
`superidea.md`, дополнение 2. Но: правило 4 ставит его после своих данных,
`proof-of-value.md` показал, что повод рождается внутри Ovre, `deep-research.md`
показал, что выигрывает петля отбора на своих данных, а не объяснение чужих
причин. Отрыв реальный, но не первый. Он вырезан в «потом» осознанно.

### Где отрыв есть в минимуме

**Ежедневный срез своих данных.** Человеку, чтобы держать то же самое, нужно
каждый день открыть 18 карточек с размерами, 47 публикаций со статистикой,
сверить со вчерашним листом, записать разницу. Моя оценка 20–25 минут в день,
10–12 часов в месяц (проверить, вопрос 2). Никто этого не делает и не будет:
`risks.md` §4 описывает, как это бросают через три недели. Агент делает это
за две минуты и 7–17 BYN в месяц, без единого пропуска, и через 30 дней у нас
есть 30 срезов × 18 вещей × размеры × все посты.

Десятикратно здесь по трём осям сразу:

- **Дешевле.** 10–12 часов человека в месяц против 17 BYN. Десятикратно при
  ставке выше ~1,5 BYN за час, то есть при любой.
- **Шире.** Человек смотрит на топ-3 вещи и последний пост. Агент - на все
  18 и на все посты, каждый день.
- **Лучше как факт.** Ни одной строки «последняя единица» из головы.

И самое важное: это единственная часть суперидеи, которую **нельзя скачать**.
Скиллы разведки, монтаж, постинг - всё в `references.md` лежит открыто, и
любой поставит их за вечер. Срез своих данных за 30 дней есть только у того,
кто его 30 дней собирал. Это принцип «возня - наш защитный барьер» из
`principles.md`, переведённый в ось отрыва.

### Как эта ось открывает следующие две

Журнал - это то, чего не хватало для двух других осей из «потом»:

1. **Отбор по метрике, а не по красоте** (Marketing Science, `deep-research.md`):
   без истории «какой пост → сколько сохранений → сколько заказов» отбирать
   не по чему. Через 2–3 месяца журнала будет по чему.
2. **Разведка конкурентов**: когда известно, что у нас работает, чужие
   паттерны сравниваются с нашими цифрами, а не читаются как эссе.

Порядок: журнал → отбор → разведка. Не наоборот, как в `superidea.md`.

### Если отрыва не окажется

Условие проверки простое. Если через 30 дней в журнале есть дыры (источник
данных о вещах не обновлялся, см. «Открыто») или Марина не открывает Telegram,
то отрыва нет, потому что нет самого журнала. Тогда сужать дальше уже некуда:
это будет сигнал, что автоматизировать нечего, а надо чинить учёт остатков и
разговор с Мариной руками. Оба условия стоят до кода, ниже.

## Открыто

- **Откуда брать остаток по размерам.** Tilda отдаёт остатки по вариантам
  только через ручной экспорт CSV из панели ([Tilda: импорт и экспорт товаров](https://help-ru.tilda.cc/online-store-payments/import-export)),
  API для этого нет. Варианты: (а) наш же сайт ovre.by, карточки товара
  публичные, доступность размеров видна - агент читает свои страницы;
  (б) Tilda CRM / вебхук заказов как источник «продалось»; (в) один раз в день
  кто-то выгружает CSV. Вариант (в) - это ровно та возня, которую бросят.
  Ставлю на (а) + (б), проверить на первой неделе.
- **Ведётся ли остаток по размерам в Tilda вообще.** Если карточка не знает
  об остатке, ни один источник не поможет. Вопрос 3.
- Время присылки. Подбираем на первой неделе.
- Где крутится: компьютер по расписанию или VPS.
