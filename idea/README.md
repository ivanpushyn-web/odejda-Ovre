# idea/ — идеи проекта Ovre

Сюда складываем идеи: продуктовые, контентные, маркетинговые, по сайту.

Правило: одна идея = один файл `YYYY-MM-DD-короткое-название.md`.

Шаблон файла:

```
# Название идеи

**Дата:** YYYY-MM-DD
**Статус:** черновик / в работе / отложено / сделано

## Суть
Одним абзацем: что это и зачем.

## Для кого / какой повод
Опора на аватар (.business/audience/avatar.md).

## Что нужно, чтобы сделать
- ...

## Заметки
```
