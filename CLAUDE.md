# Ovre - навигация по проекту

Ovre (ÓVRE) — беларусский бренд женской одежды премиум-сегмента: костюмная
группа и вечерние образы для женщин 27–37. Продажи через Instagram @ovre.brand
и сайт ovre.by (Tilda). ИП, Минск.

Подробности - в `.business/INDEX.md`.

## Структура репозитория

```
Odejda Ovre/
├── CLAUDE.md                ← этот файл, правила работы
├── TROUBLESHOOTING.md       ← решения типовых проблем Claude Code
├── .business/               ← скрытая папка, бизнес-контекст (не в git)
├── plans/                   ← технические планы (один план = одна задача)
├── retrospectives/          ← рефлексии после каждой сессии
└── prompts/                 ← библиотека готовых промптов
```

## Стек

Сайт — **Tilda** (Store-модуль), домен ovre.by, тёмная тема, лого ÓVRE.
Своего фронта/бэка нет. Работа над сайтом = в пределах Tilda: блоки, Zero-block,
T-store settings, кастомный CSS/JS через T123 и «Настройки → HTML-код».
Отдельные задачи (лендинги, квизы, автоматизации, интеграции, парсеры,
контент-скрипты) — стек подбираем под задачу, фиксируем в плане.

## Ключевые принципы работы

1. **Всегда читай `.business/INDEX.md`** перед задачей про бизнес. Перед текстами
   и дизайном — обязательно `.business/company/values.md` +
   `.business/audience/avatar.md` + `.business/assets/brand-guidelines.md`.
2. **Один чат - одна задача.** Разные задачи = разные чаты.
3. **Ищи в `prompts/INDEX.md` до того как писать промпт с нуля.**
4. **План для каждой новой задачи** - в `plans/YYYY-MM-DD-название.md`:
   - Фазы со статусами `[ ]` / `[x]`
   - Итоговый блок: реализовано / что осталось
   - Актуализация плана после каждой сессии
5. **Ретроспектива в конце каждой сессии** - в `retrospectives/YYYY-MM-DD_HH-MM_название.md`.
6. **Перед публикацией** (сайт, реклама, пост) - показывай финальный вариант мне,
   не выкладывай сам.
7. **Коммить только свои изменения.** Никаких `git add .` - файлы поименно.
8. **Данные с коротким TTL** (цены, наличие, даты акций) - в источнике (Tilda /
   таблица), не в тексте кода.

## Тон бренда (для любых текстов)

Сдержанный премиум, editorial. Про образ и результат («как ты будешь выглядеть
и что почувствуешь»), а не про «хит сезона» и «успей купить». Без обилия
восклицаний и эмодзи. Допустима короткая англоязычная микрокопия + русская
расшифровка. Опора на посадку, крой, ткань, повод.

## Безопасность

- Не скармливай Клоду паспорта, пароли, ПДн клиентов, реквизиты ИП, ключи.
- `.env` не читай целиком - только через `grep` по конкретной переменной.
- Перед Bypass Permissions - git-коммит.
- Перед установкой любого скила / MCP - аудит через `prompts/setup/08-skills-install.md`.

## Триггеры операционного планирования

| Фраза | Действие |
|---|---|
| «давай спланируем неделю» | `.business/goals/monthly.md` → создай `.business/execution/YYYY-WNN.md` |
| «добавь задачу» | В файл текущей недели или в `.business/execution/backlog.md` |
| «итоги недели» | Заполни секцию «Итог недели» |
