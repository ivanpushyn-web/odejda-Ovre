# Ретро: MVP контент-завода

**Дата:** 2026-09-10 10:49
**Длительность:** ~30 минут
**План:** без плана, шаг цепочки idea/ (… → risks → principles → mvp)

## 1. Задача

Вырезать из суперидеи самую маленькую версию, которая уже работает: тип
проекта, минимум одной фразой, список «потом», расчёт качество / себестоимость
на цифрах автора, ось десятикратного отрыва. Результат - `idea/mvp.md`.

## 2. Как решал

Claude Code, папка открыта напрямую. Прочитаны целиком все файлы idea/
(superidea, proof-of-value, why-now, references, deep-research, precedents,
risks, principles) и `.business/` (team, costs, unit-economics, content,
competitors, funnel, channels, objections, products, monthly, kpi), оба ретро
пред-мортема и ретро принципов. Цены токенов взяты из справки claude-api
(Opus 5 $5/$25, Sonnet 5 $2/$10 за 1M), не из памяти. Проверил через поиск,
что Tilda отдаёт остатки по вариантам только ручным CSV-экспортом, API нет.

## 3. Решил?

- [x] Частично: `idea/mvp.md` написан целиком, но таблица сравнения держит
  знаки «?» на стороне человека. Семь вопросов к автору внутри файла. Вывод
  по расчёту намеренно не написан до цифр.

## 4. Что можно было лучше

- Главный ход файла: отрыв не в сторис (там его нет, +10%), а в ежедневном
  срезе своих данных, который человек не собирает вообще. К этому можно было
  прийти быстрее из `principles.md`, там это уже названо барьером.
- Ссылки на Tilda CSV нашёл, но не проверил, ведётся ли остаток по размерам
  у Ovre в принципе. Это первый вопрос автору, без него весь поток пустой.

## 5. Как было / как стало

- **Было:** сцена из `proof-of-value.md` без ответа, зачем она десятикратна,
  и суперидея, где центр тяжести на конкурентах.
- **Стало:** минимум = утренний поток «срез вещей и постов → одна сторис с
  фактической строкой "почему сегодня" → Telegram → журнал да/нет». Порядок
  осей перевёрнут: журнал → отбор по метрике → разведка конкурентов.
  Шестнадцать функций суперидеи вынесены в «потом» с условием возврата.
