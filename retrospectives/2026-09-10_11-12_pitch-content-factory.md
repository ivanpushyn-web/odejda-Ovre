# Ретро: итоговый нарратив контент-завода (pitch)

**Дата:** 2026-09-10 11:12
**Длительность:** ~20 минут
**План:** без плана, завершающий шаг цепочки idea/ (superidea → … → vision → pitch)

## 1. Задача

Собрать всю папку `idea/` в один связный текст по методологии нарративного
меморандума (Amazon: шестистраничник и PR/FAQ вместо слайдов), с которым
автор выйдет «на совет директоров». Проверить, не потерялась ли единица
смысла, нет ли противоречий между файлами и пустых мест. Результат -
`idea/pitch.md`.

## 2. Как решал

Claude Code, папка открыта напрямую. Прочитаны целиком все десять файлов
`idea/` (~310 КБ). Перекрёстно проверены факты в `.business/` (team.md,
goals/annual, kpi, monthly, marketing/content) и ретро сессий 10.09.
Структура: суть одним абзацем → боль → как замысел сместился по ходу
разбора → почему сейчас (отдельно для суперидеи и для минимума) → что беру
у чужих (в минимум сразу / позже с условием / не беру) → первая польза →
минимальная версия и ось отрыва → экономика → риски и красные линии →
видение → порог закрытия → до первой строчки кода → FAQ → источники цифр →
«Додумать». Дефис вместо длинного тире по всему тексту, проверено grep.

## 4. Что можно было лучше

- Текст длинный. Для реального «прочитать молча за 20 минут» может
  понадобиться версия на две страницы; сейчас приоритет был «ни одна деталь
  не потеряется», и это выполнено за счёт длины.
- Раздел «что беру у чужих» остался плотным перечислением в прозе. Это
  компромисс между «не список» и «не потерять сотню приёмов».

## 5. Как было / как стало

- **Было:** десять файлов с разными датами, две меры успеха, три версии
  ответа «кто в кадре», не обновлённые после поворотов superidea, why-now и
  proof-of-value.
- **Стало:** один текст с явной историей поворотов (разведка → идеи →
  производство перевернулось в журнал → отбор → разведка), честным «почему
  сейчас» отдельно для минимума, и списком из 27 пунктов, где каждое
  расхождение названо с файлами по обе стороны.
